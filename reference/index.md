# Package index

## All functions

- [`CCDB`](https://nigelhojinker.github.io/scpeaker/reference/CCDB.md) :
  Mapped CellChat (v2) interaction database
- [`CPDB`](https://nigelhojinker.github.io/scpeaker/reference/CPDB.md) :
  Mapped CellPhoneDB (v5) interaction database
- [`crosscheck()`](https://nigelhojinker.github.io/scpeaker/reference/crosscheck.md)
  : Comparing CellChat and CellPhoneDB results
- [`filter_cellchat()`](https://nigelhojinker.github.io/scpeaker/reference/filter_cellchat.md)
  : Subsetting CellChat object to contain interactions significant in
  both CCC tools
- [`pull_netslot()`](https://nigelhojinker.github.io/scpeaker/reference/pull_netslot.md)
  : Extract all relevant interactions from CellChat analysis
- [`run_cellchat()`](https://nigelhojinker.github.io/scpeaker/reference/run_cellchat.md)
  : Run CellChat (v2.2.0) in R
- [`run_cellphonedb()`](https://nigelhojinker.github.io/scpeaker/reference/run_cellphonedb.md)
  : Run CellPhoneDB version 5 in R
- [`scpeaker()`](https://nigelhojinker.github.io/scpeaker/reference/scpeaker.md)
  : Run CellChat (v2) and/or CellPhoneDB (v5) for cell-cell
  communication analysis
- [`seu.NL`](https://nigelhojinker.github.io/scpeaker/reference/seu.NL.md)
  : Demo dataset prepared from CellChat tutorial data
